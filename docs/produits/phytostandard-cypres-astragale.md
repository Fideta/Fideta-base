# 🔴 Note Fideta : **E – Score : 35/100**

**Pertinence clinique limitée**

L’association Cyprès + Astragale repose sur deux extraits végétaux traditionnellement (en Europe pour le cyprès, en Chine pour l'astragale notamment) utilisés pour le confort respiratoire ou le soutien immunitaire. 

- Aucun essai clinique n’a évalué **ce produit**, **cette association**, ni **ces doses**.  
- **Cyprès (noix)** : aucune donnée clinique par voie orale ; uniquement des données in vitro ou animales → extrapolation impossible.  
- **Astragale (racine)** : quelques essais humains existent mais dans des **contextes très spécifiques** (infections récidivantes chez l’enfant, insuffisance rénale, oncologie), avec des préparations et doses **sans rapport** avec ce produit.  
- Aucun argument clinique ne permet de valider l’usage en **prévention** ou en **soutien immunitaire** chez l’adulte sain, y compris après 65 ans.

Les usages « traditionnels » ne constituent pas une preuve d’efficacité. Les données disponibles ne permettent pas d’attribuer un bénéfice clinique clair.

# ⚠️ Sécurité et précautions

### Effets secondaires / indésirables potentiels
- Troubles digestifs légers.  
- Réactions allergiques possibles (astragale = Fabacées).  
- Effet laxatif si doses élevées (polydextrose, fibre).

### Contre-indications / prudence
- **Grossesse / allaitement** : données insuffisantes → éviter.  
- **Antécédents personnels/familiaux de cancer du sein** : prudence (astragale = effets oestrogéniques expérimentaux).  
- **Pathologie auto-immune ou immunosuppression** : risque théorique de modulation immunitaire.  
- **Traitements lourds (oncologie, immunosuppresseurs)** : prudence.

### Interactions possibles
- **Immunosuppresseurs** : antagonisme potentiel.  
- **Antidiabétiques / antihypertenseurs** : théoriques (effets métaboliques observés à fortes doses d’astragale).

### Dose maximale
- Ne pas dépasser **6 comprimés/j**, aucune DJA officielle pour ces extraits.
